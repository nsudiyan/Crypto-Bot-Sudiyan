# Торговая Стратегия и Принципы Платформы

В данном документе описана стратегия прибыльной торговли на крипторынке, основанная на скальпинге, а также принципы использования платформы для отбора монет и совершения сделок.

## 1. Основная стратегия: Скальпинг

Стратегия торговли базируется на **скальпинге** — краткосрочной торговле внутри дня с целью получения небольшой, но частой прибыли.
Ключевой элемент стратегии — анализ биржевого стакана, поиск крупных лимитных заявок (плотностей) и торговля на отскок от них или на пробой. Этот подход аналогичен методам, используемым в терминалах вроде Tiger Trade.

## 2. Отбор монет (Скрининг)

Для успешного скальпинга необходимо отбирать волатильные и активные монеты с выраженными аномалиями. Для этого используются специализированные радары и скринеры:

### 2.1. Trading Pulse
*   **Ссылка:** [Trading Pulse Radar](https://trading-pulse-mu.vercel.app/#/radar) (Кастомный радар).
*   **Назначение:** Исследовательский радар для выявления ранних аномалий цены, объёма и изменения структуры рынка. Помогает находить монеты, которые в данный момент активны или готовятся к сильным движениям.

### 2.2. RedScalp Screener
*   **Ссылка:** [RedScalp Screener](https://redscalp.com/screener)
*   **Назначение:** Отслеживание лимитных заявок (плотностей) в стакане по множеству монет. Помогает быстро находить инструменты, где крупные игроки выставили большие объемы на покупку или продажу, что служит отличной точкой входа для скальпинга.

## 3. Торговый терминал (Исполнение сделок)

Для выставления ордеров и контроля позиций используется профессиональный привод для скальпинга.

### MetaScalp
*   **Ссылка:** [MetaScalp](https://metascalp.io/)
*   **Назначение:** Основной терминал для торговли через биржевой стакан.
*   **Принципы управления (Управление мышью):** Описаны в [Roadmap/Документации MetaScalp](https://metascalp.gitbook.io/metascalp/mouse-control).
    *   **LONG:** ЛКМ ниже спреда (лимитка на покупку), ЛКМ выше спреда (покупка по рынку).
    *   **SHORT:** ПКМ выше спреда (лимитка на продажу), ПКМ ниже спреда (продажа по рынку).
    *   **Снятие заявок:** Клик колесиком или нажатие на крестик.
    *   **Stop Loss / Take Profit:** Горячая клавиша + ЛКМ.
    *   **Закрытие позиции:** Горячая клавиша `Left Alt` + ЛКМ/ПКМ.

## 4. Рабочий процесс (Workflow)

1.  **Анализ рынка:** Открытие радара *Trading Pulse* для поиска монет с аномальными объемами и изменениями структуры.
2.  **Поиск плотностей:** Использование *RedScalp Screener* для обнаружения крупных лимитных плотностей в стаканах отобранных монет.
3.  **Исполнение:** Открытие стакана выбранной монеты в терминале *MetaScalp*.
4.  **Торговля:** Совершение сделок (вход лимитками от плотностей или по рынку на пробой) с использованием быстрых команд мыши (ЛКМ/ПКМ).
5.  **Контроль рисков:** Обязательная установка Stop Loss на каждую сделку.
